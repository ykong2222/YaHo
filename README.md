## 정보 이용 탐색(= 휴리스틱 정보) : 비슷한 문제에 대한 이전 경험이나 지식을 바탕으로 어떤 기준을 판단하여 결정하는 탐색 방법
### -> 이용 : 문제의 해가 정확하게 나오지 않을 때 또는 정해진 시간 안에 모든 탐색을 완료하지 못 할 때 유용 but 비효율적임.

### -> 특징 : 한 번 선택하여 내려가면 같은 레벨의 다른 노드를 선택하는 것을 고려하지 않음
### -> 이용 : 지역적으로도 최적의 해이면서 전체적으로도 최적의 해를 찾는 문제에 적합(작은 범위를 할 수 있다면 큰 범위의 문제를 해결할 수 있음.)
## -> 평가 함수(현재 위치와 목표 위치가 일치하는 퍼즐의 개수)의 값을 통해서 
###### 데이터 저장 사례 : 열이 발생하기 때문에 물이 담가서 사용(반도체라서 가능함.) -> 열 발생 >물 증발 > 따라서 에너지 손실이 큼 => 정보 이용 탐색을 이용하여 노드를 줄여 효율적이게끔 한다.
