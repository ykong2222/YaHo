## 합성곱 신경망 : 딥러닝 모델 중 이미지 분류에 뛰어난 성능을 보이는 모델 -> 합성곱층, 풀링층, 완전 연결층
### 합성곱층 -> 차원을 축소될 수 있음 / 데이터, 공간 등을 축소할 수 있음 / 효율적
### 풀링층 : 합성곱층을 통과한 데이터를 여러 개의 작은 영역으로 쪼갠 후 각 영역을 대표하는 값 하나 만을 출력함 -> 풀링층을 통과하면 데이터의 크기를 줄이면서도 중요한 정보를 남겨 학습이 쉬워짐.
### 완전 연결층 : 합성곱층과 풀링층을 여러 번 통과하여 추출한 이미지의 특징을 연결한 것
## 생성형 인공지능 : 텍스트 오디오 이미지 등 기존 컨텐츠를 만드는 것
### -> 생성적 절대 신경망 : 데이터를 생성하는 생성자와 데이터가 진짜인지 가짜인지 구분하는 감별자로 구성됨. -> 이 기능이 탑재되면서 자세하고 정확하게 이미지 생성을 할 수 있게 됨.
